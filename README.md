# 🏠 King County House Price Analysis Dashboard

An interactive **Power BI dashboard** that analyzes housing prices in King County, Washington.
The dashboard provides insights into price distribution, geographical patterns, and the impact of property features such as bedrooms, house grade, renovation status, and living area on house prices.

This project demonstrates **data analysis, visualization, and dashboard design skills** using real-world housing data.

---

# 📊 Project Overview

The goal of this project is to explore and visualize housing market trends using the **King County housing dataset**.

The dashboard allows users to:

* Understand **overall housing market statistics**
* Analyze **price distribution**
* Explore **geographical price patterns**
* Evaluate how **property features affect house prices**

---

# 🛠 Tools & Technologies

* **Power BI** – Dashboard creation and visualization
* **Excel / CSV Dataset** – Data source
* **GitHub** – Version control and project sharing

---

# 📁 Dataset

Dataset used: **King County House Sales Dataset**

The dataset contains information about house sales in King County, including:

* Price
* Bedrooms
* Bathrooms
* Living Area (Sqft)
* House Grade
* Renovation Status
* Zip Code
* Latitude & Longitude
* Year Sold

---

# 📌 Dashboard Features

### 1️⃣ Market Overview

Key housing market metrics:

* Total Houses Sold
* Average Price
* Maximum Price
* Median Price

---

### 2️⃣ Price Distribution Analysis

Visualizes how house prices are distributed across the market using a **histogram**, helping identify common price ranges and potential outliers.

---

### 3️⃣ Geographic Price Analysis

A **map visualization** displays house prices across locations using latitude and longitude to reveal regional price patterns.

---

### 4️⃣ Price vs Living Area

A **scatter plot** showing the relationship between:

* Living area (square feet)
* House price

This helps identify how property size influences price.

---

### 5️⃣ Price by Bedrooms

A **bar chart** analyzing the average price based on the number of bedrooms.

---

### 6️⃣ Price by House Grade

Displays how the **quality grade of a house** affects its market price.

---

### 7️⃣ Renovation Impact

Compares average prices between:

* Renovated houses
* Non-renovated houses

---

### 8️⃣ House Age vs Price

Analyzes how the **age of a house** influences its price.

---

# 🎛 Interactive Filters

# 📈 Key Insights

Some insights observed from the dashboard:

* Houses with **larger living areas generally have higher prices**.
* **Higher house grades** significantly increase property value.
* Renovated houses often show **higher average prices** compared to non-renovated properties.
* Certain geographic areas have **clusters of high-priced properties**.
